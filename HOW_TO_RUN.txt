HOW TO RUN THIS PROJECT (QUICK & EASY):
------------------------------------------------------------------------
Option 1: 1-Click Launch (Recommended for Windows)
  1. Simply double-click on "start.bat"
  2. It will automatically check dependencies and open the live portal 
     in your web browser at: http://localhost:5173

Option 2: Terminal / Manual Launch (Windows / Mac / Linux)
  1. Open Terminal in this folder.
  2. Install dependencies:
       npm install
       pip install -r backend/requirements.txt
  3. Run the development server:
       npm run dev
